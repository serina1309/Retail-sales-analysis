# Retail-sales-analysis
Retail sales analysis using SQL and Python

Project Overview

This project aims to analyze retail sales data to understand sales performance across different regions, product categories, and products.

Objective

- Calculate total sales revenue.
- Identify top-selling products.
- Compare sales across regions.
- Analyze product category performance.
- Understand the impact of discounts on sales.

Tools

- Google Sheets
- SQL / MySQL
- Python

Dataset

The dataset contains fictional retail order information, including order dates, regions, product categories, units sold, selling prices, discounts, and unit costs.

Analysis Results

The initial analysis was performed using Google Sheets on a fictional dataset of 20 retail orders.

Key Findings

- Total Sales Revenue: ₹1,38,300
- Best-Selling Product by Units: Water Bottle, with 54 units sold
- Region with the Most Units Sold: East, with 61 units
- Region with the Highest Revenue: South, generating ₹39,652.50

Business Insight

The East region sold the most units, but the South region generated the highest revenue. This shows why both sales volume and revenue are useful when comparing regional performance.
